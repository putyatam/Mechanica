# Mechanica 0.4

Mechanica — игровая инженерная песочница, в которой механизмы строятся из низкоуровневых физических деталей, а не из готовых «магических» устройств.

## Что изменилось в 0.4

### Графический редактор собственных блоков

Редактор теперь состоит из трёх рабочих областей:

1. слева — структура компонентов;
2. в центре — живой 3D-просмотр итогового блока;
3. справа — параметры выбранного компонента.

3D-просмотр можно вращать ПКМ и масштабировать колёсиком.

Произвольные профили имеют отдельное 2D-поле:
- вершины видны на сетке;
- вершины перетаскиваются мышью;
- двойной щелчок добавляет новую вершину;
- координаты можно доводить численно;
- для окружностей не нужно расставлять точки: есть цилиндры, сферы, трубы и тело вращения.

### CSG

Каждый компонент имеет одну из операций:
- Добавить;
- Вычесть;
- Пересечь.

Если используется Вычесть/Пересечь, итоговый блок компилируется в объёмную CSG-сетку.
После вычисления занятые ячейки жадно объединяются обратно в крупные прямоугольные объёмы.

Это означает:
- отверстия остаются настоящими отверстиями;
- вогнутые формы остаются вогнутыми;
- физика получает compound collision вместо одного выпуклого hull;
- количество collision primitives сильно уменьшается по сравнению с «одна ячейка = один shape».

Точность CSG регулируется в редакторе блока.

### Верхние инструменты

На верхней панели появились четыре инструмента:

- Симметрия;
- Поворот;
- Перемещение;
- Масштаб.

Для перемещения, поворота и масштаба используется ImGuizmo:
- перемещение — три стрелки;
- вращение — три кольца;
- масштабирование — три осевых манипулятора.

Инструменты работают и с одним блоком, и с множественным выделением.

Под выбранным инструментом появляется маленькая панель:
- Симметрия: X / Y / Z;
- Перемещение: шаг в метрах;
- Поворот: шаг в градусах;
- Масштаб: шаг масштаба.

### Симметрия

Включённые X/Y/Z создают зеркально расположенные копии относительно мировых координатных плоскостей.

Превью зеркальных копий показывается до установки.

### Новая привязка

Касание и привязка теперь окончательно разделены.

Обычный режим:
- наводишь новый блок на место;
- все соприкасающиеся блоки подсвечиваются зелёным;
- по умолчанию новая деталь прикрепится ко всем подсвеченным соседям.

Редактирование привязки:
1. удерживаешь Alt;
2. размещаемый блок замораживается в текущем положении;
3. мышь освобождается;
4. ЛКМ по подсвеченному соседу переключает связь:
   - зелёный = связь будет;
   - красный = связи не будет;
5. отпускаешь Alt;
6. курсор возвращается ровно в точку, из которой был начат режим;
7. можно продолжать двигать размещаемый блок.

### Материалы теперь влияют на разрушение

Явные жёсткие связи между блоками во время симуляции больше не являются «вечной сваркой».

Каждая связь компилируется в Jolt FixedConstraint.

После каждого physics step:
- считывается линейный и угловой constraint impulse;
- импульс переводится в силу/момент;
- по оценочной площади контакта считается напряжение;
- по модулю Юнга вычисляется упругая деформация `ε = σ / E`;
- после превышения yield strength накапливается пластическое повреждение;
- при превышении tensile strength или накоплении критического повреждения связь разрушается.

В верхней строке симуляции отображаются:
- максимальное напряжение;
- максимальная упругая деформация;
- количество связей в текучести;
- количество разрушенных связей.

Это пока не полноценный FEM по объёму детали: локальная деформация формы сетки не пересчитывается. Но Young's modulus, yield strength и tensile strength уже участвуют в структурной физике, а разрушение основано на нагрузке, а не на HP.

## Производительность

В 0.4 есть два разных уровня сложности:

- один пользовательский блок может состоять из большого количества компонентов/CSG-ячеек, но остаётся одним rigid body;
- разные размещённые блоки, между которыми игрок создал разрушаемые связи, являются отдельными rigid bodies и соединяются constraints.

Это дороже старого «всю сваренную конструкцию слить в один body», но необходимо для измерения сил и физического разрушения.

Следующий оптимизационный слой — автоматически объединять большие ненагруженные участки конструкции в кластеры и динамически разделять их только там, где нужно измерять напряжения/разрушение.

## Управление

- ЛКМ — установить или выбрать блок;
- Ctrl + ЛКМ — множественное выделение;
- ПКМ + движение — вращение камеры;
- колесо — масштаб камеры;
- B — библиотека;
- G — сетка;
- R — повернуть размещаемую деталь;
- Alt — заморозить установку и редактировать связи;
- Delete / X — удалить выбранное;
- Space — Build / Simulation;
- F2 — физическая лаборатория.

Для выбранной группы используйте верхние Move / Rotate / Scale gizmo.

## Сборка

Требования:

- Git;
- CMake 3.25+;
- Visual Studio 2022/2026 с Desktop development with C++.

```powershell
cmake -S . -B build -A x64 -DUSE_STATIC_MSVC_RUNTIME_LIBRARY=OFF
cmake --build build --config Release --parallel
.\build\Release\Mechanica.exe
```

CMake автоматически получает:
- SDL3;
- Jolt Physics 5.6.0;
- Dear ImGui;
- ImGuizmo 1.10;
- nlohmann/json.
